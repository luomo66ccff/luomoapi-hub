Public Gateway

API Documentation

Public routes are called through /api/public/v1/{route}. Enabled routes require a scoped LuomoAPI key unless marked anonymous.

Authentication

Use either Authorization: Bearer lapi_xxx or X-API-Key: lapi_xxx. API keys are issued after email verification, admin approval, and API key request review.

Scope matching is exact. A key with astrbot:read can call AstrBot read routes; a key with luomocore:health can call LuomoCore health. Admin-issued wildcard keys may use *.

Rate limits and quotas are enforced per API key. The default issued-key policy is currently 60/min and 1000/day, but admins can set different limits per key.
